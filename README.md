Personal academic blog of [ZHANG Baizhou](https://zhangbz764.github.io/).

Made with Jekyll using the [Tale](https://github.com/chesterhow/tale/) theme.

## CV authoring

编辑 `_data/cv.yml` 后，运行 `npm run cv:preview` 可本地预览英文和中文简历。运行 `npm run cv:check` 检查选择和必填字段。安装 Ruby 与 Chromium 依赖后，`npm run cv:build` 会在本地生成完整 Jekyll 网站和全部 CV 下载文件。
